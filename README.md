# Agent Chat Simulator

A web-based simulation that allows two AI agents to converse about a user-defined topic with customizable personalities. The agents use local AI models (via Ollama) to generate contextual, personality-driven responses.

## Features

- **Customizable Topics**: Set any discussion topic for the agents to converse about
- **Personality Configuration**: Assign names and traits (e.g., caveman, gamer, curious, analytical) to each agent
- **Local AI Powered**: Uses Ollama with gemma4:e4b model for intelligent, contextual responses
- **Anti-Looping Protection**: Sophisticated prompts and response validation prevent repetitive or garbled output
- **Proper Turn-Taking**: Agents respond to each other with appropriate timing delays
- **User Participation**: Optionally join the conversation yourself
- **Fallback System**: Template-based responses if Ollama is unavailable
- **Clean UI**: Responsive design with clear visual distinction between agents

## How It Works

1. User sets a topic and configures two agents with names and personality traits
2. When "Start Chat" is clicked:
   - Agent 1 speaks first about the topic
   - After a delay, Agent 2 responds to Agent 1's message
   - After another delay, Agent 1 responds to Agent 2's message
   - This alternating pattern continues with proper timing
3. Each agent's response is generated by:
   - Sending a structured prompt to the local Ollama instance
   - Including agent identity, topic, conversation history, and strict behavioral rules
   - Receiving and cleaning the response to ensure quality and relevance
   - Falling back to trait-specific templates if Ollama fails

## Technical Specifications

### Frontend
- **HTML5/CSS3/JavaScript**: Vanilla web technologies
- **Responsive Design**: Works on desktop and mobile browsers
- **DOM Manipulation**: Dynamic chat interface updates

### Backend
- **Node.js/Express.js**: Lightweight API server
- **Ollama Integration**: Communicates with local Ollama instance at `http://localhost:11434`
- **Model**: `gemma4:e4b` (9.6 GB parameter-efficient model)
- **Inference Settings**:
  - Temperature: 0.4 (focused, less random)
  - Top P: 0.8 (nucleus sampling)
  - Repeat Penalty: 1.3 (strong anti-loop measure)
  - Max Tokens: 300 (`num_predict`)
  - Stop Sequences: Prevents speaker label repetition and common artifacts

### Conversation Flow
- **Agent 1 → Agent 2**: 0s → 3s delay
- **Agent 2 → Agent 1**: 3s → 6s delay
- **Full Cycle**: 7 seconds (includes 1s buffer)
- **History Limit**: Last 2 exchanges only (prevents context confusion)
- **Response Length**: ~500 characters maximum
- **Validation**: Post-processing to remove artifacts, ensure proper punctuation, and limit repetition

### Personality Traits Supported
- **caveman**: Primitive speech, focuses on survival and physical tasks
- **gamer**: Video game metaphors, XP grinding, boss raids
- **curious**: Asks questions, seeks understanding, explores implications
- **analytical**: Breaks down concepts, looks at data, thinks logically
- **skeptical**: Questions assumptions, looks for evidence, expresses doubt
- **optimistic**: Focuses on positives, sees opportunities, expresses hope
- **pragmatic**: Focuses on practical solutions, considers feasibility

## Setup Instructions

### Prerequisites
1. [Node.js](https://nodejs.org/) (v14+ recommended)
2. [Ollama](https://ollama.ai/) installed and running
3. The `gemma4:e4b` model pulled: `ollama pull gemma4:e4b`

### Installation
1. Clone or copy this repository
2. Install dependencies: `npm install`
3. Start Ollama: `ollama serve` (in a separate terminal)
4. Start the API server: `node server.js`
5. Serve the frontend: `python3 -m http.server 8080` or similar
6. Access at `http://localhost:8080`

### Alternative Deployment
- The frontend (HTML/CSS/JS) can be hosted on any static web server
- The backend (Node.js) can be deployed to any Node.js hosting service
- Ensure CORS settings allow communication between frontend and backend if hosted separately

## Customization

### Changing the Model
Edit `server.js` line: `const MODEL = 'gemma4:e4b';`

### Adjusting Timing
Edit `script.js` in the `setInterval` and `setTimeout` calls in the `startChat` function.

### Adding New Traits
1. Add to `traitResponses` object in `generateImprovedMockResponse` function in `server.js`
2. Add to `templates` object in `generateMockResponse` function in `script.js`
